# Security policy

## Scope

This project is analysis software for a student rocket team. It deliberately contains no secrets,
cloud service, actuator protocol, or recovery deployment path. Reports involving local file access,
dependency vulnerabilities, unsafe parsing, or an accidental hardware-control path are in scope.

## Reporting

Do not publish exploitable details in a public issue. Contact the project maintainers privately
through the team’s approved university channel, including the affected commit, reproduction steps,
impact, and a proposed mitigation. Remove credentials, private telemetry, and personal data from
the report.

## Safety note

Security fixes do not constitute flight approval. Any change that could influence avionics, radio,
recovery, or control hardware requires an independent software and safety review.
